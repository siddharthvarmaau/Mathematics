The core idea

Integration reverses differentiation

\[ \frac{d}{dx}F(x) = f(x) \iff \int f(x)\,dx = F(x) + c \]

If differentiating $F$ gives $f$, then integrating $f$ gives $F$ back, plus an unknown constant $c$ (because the derivative of any constant is 0). Every rule on this sheet is a derivative rule read backwards. This also gives you a free check: differentiate your answer and you should get the integrand.

Example

\[ \frac{d}{dx}\left[\tfrac15(x^2-1)^5\right] = (x^2-1)^4\cdot 2x \quad\Longrightarrow\quad \int 2x(x^2-1)^4\,dx = \tfrac15(x^2-1)^5 + c \]

Introduction to integrationAntiderivatives, powers, constant and sum rules, simplifying, applications

Antiderivative, primitive, indefinite integral

\[ F \text{ is a primitive of } f \iff F'(x) = f(x), \qquad \int f(x)\,dx = F(x) + c \]

"Antiderivative" and "primitive" mean the same thing: a function whose derivative is $f$. There is never just one. Adding any constant gives another, because constants differentiate to 0. The indefinite integral $\int f(x)\,dx$ is the whole family, written $F(x)+c$. Graphically, the family is the same curve shifted up and down.

Example

\[ \frac{d}{dx}(x^2) = \frac{d}{dx}(x^2+3) = \frac{d}{dx}(x^2-7) = 2x \quad\Longrightarrow\quad \int 2x\,dx = x^2 + c \]

Power rule: natural numbers, integers, fractions

\[ \int x^n\,dx = \frac{x^{n+1}}{n+1} + c, \quad n \neq -1 \qquad\qquad \int k\,dx = kx + c \]

Add one to the power, then divide by the new power. The same rule covers every power except $-1$. A constant integrates to the constant times $x$, because $k = kx^0$.

Examples

\[ \text{Natural: } \int x^5\,dx = \frac{x^6}{6} + c \qquad \text{Constant: } \int 7\,dx = 7x + c \] \[ \text{Negative integer: } \int x^{-3}\,dx = \frac{x^{-2}}{-2} + c = -\frac{1}{2x^2} + c \] \[ \text{Fraction: } \int x^{2/3}\,dx = \frac{x^{5/3}}{5/3} + c = \frac35x^{5/3} + c \] \[ \text{Negative fraction: } \int x^{-1/2}\,dx = \frac{x^{1/2}}{1/2} + c = 2\sqrt{x} + c \] \[ \text{Mixed (5C): } \int\frac{1}{x^8}\,dx = -\frac{1}{7x^7} + c \qquad \int\sqrt{x}\,dx = \frac23x^{3/2} + c \]

Constant multiplier rule and sum rule

\[ \int k\,f(x)\,dx = k\int f(x)\,dx \qquad\qquad \int\big(f(x) \pm g(x)\big)\,dx = \int f(x)\,dx \pm \int g(x)\,dx \]

Constants come outside; sums and differences split into separate integrals. One $+c$ at the end covers all terms. These rules do not extend to products or quotients.

Example

\[ \int(6x^2 - 4x + 5)\,dx = 6\cdot\frac{x^3}{3} - 4\cdot\frac{x^2}{2} + 5x + c = 2x^3 - 2x^2 + 5x + c \]

Simplify the integrand first

There is no product or quotient rule for integration. Before integrating, turn the integrand into a sum of powers of $x$: expand brackets, split fractions over a single-term denominator, and rewrite roots and reciprocals as powers.

Examples

\[ \text{Expand: } \int(x+2)(x-3)\,dx = \int(x^2 - x - 6)\,dx = \frac{x^3}{3} - \frac{x^2}{2} - 6x + c \] \[ \text{Expand a square: } \int(\sqrt{x}+1)^2\,dx = \int(x + 2x^{1/2} + 1)\,dx = \frac{x^2}{2} + \frac43x^{3/2} + x + c \] \[ \text{Split a fraction: } \int\frac{x^4 - 3x^2}{x^2}\,dx = \int(x^2 - 3)\,dx = \frac{x^3}{3} - 3x + c \] \[ \int\frac{3x^2 + \sqrt{x}}{x}\,dx = \int\left(3x + x^{-1/2}\right)dx = \frac{3x^2}{2} + 2\sqrt{x} + c \] \[ \text{Root times bracket: } \int\sqrt{x}\,(x-1)\,dx = \int\left(x^{3/2} - x^{1/2}\right)dx = \frac25x^{5/2} - \frac23x^{3/2} + c \] \[ \text{Reciprocals: } \int\frac{1}{2x^3}\,dx = \frac12\int x^{-3}\,dx = -\frac{1}{4x^2} + c \qquad \int\frac{4}{\sqrt{x}}\,dx = 4\int x^{-1/2}\,dx = 8\sqrt{x} + c \]

In $\frac{1}{2x^3}$ only $x$ is cubed, so it is $\frac12x^{-3}$, not $(2x)^{-3}$.

Applications of the primitive: finding c

\[ f(x) = \int f'(x)\,dx = F(x) + c, \qquad \text{then substitute a known point to solve for } c \]

When you know the gradient function (or velocity, or rate of change) and one point the function passes through, integrate, substitute the point, and solve for $c$. The final answer is a specific function with no $c$ left.

Example: curve through a point

\[ f'(x) = 3x^2 - 4x, \quad f(1) = 5 \] \[ f(x) = x^3 - 2x^2 + c \;\Rightarrow\; 1 - 2 + c = 5 \;\Rightarrow\; c = 6 \;\Rightarrow\; f(x) = x^3 - 2x^2 + 6 \]

Example: motion

\[ v(t) = \frac{ds}{dt} = 6t - 3t^2, \quad s(0) = 2 \] \[ s(t) = 3t^2 - t^3 + c \;\Rightarrow\; 0 - 0 + c = 2 \;\Rightarrow\; s(t) = 3t^2 - t^3 + 2 \]

Example: second derivative (two constants)

\[ f''(x) = 6x, \quad f'(1) = 0, \quad f(0) = 2 \] \[ f'(x) = 3x^2 + c_1 \;\Rightarrow\; 3 + c_1 = 0 \;\Rightarrow\; c_1 = -3 \] \[ f(x) = x^3 - 3x + c_2 \;\Rightarrow\; c_2 = 2 \;\Rightarrow\; f(x) = x^3 - 3x + 2 \]

Find each constant before integrating again. Each integration introduces its own constant, and each needs its own condition.

Exponential rules

\[ \int e^{x}\,dx = e^{x} + c \qquad \int e^{ax+b}\,dx = \frac{1}{a}e^{ax+b} + c \qquad \int f'(x)\,e^{f(x)}\,dx = e^{f(x)} + c \]

$e^x$ is its own derivative. When the exponent is something else, the chain rule would multiply by the derivative of the exponent, so integrating needs that derivative to be present (or a constant multiple of it). Used in the 5C mixed exercises and throughout 6A.

Example (5C mixed integration)

\[ \int x\,e^{2x^2+3}\,dx: \quad f(x)=2x^2+3,\; f'(x)=4x, \text{ so } x = \tfrac14 f'(x) \] \[ = \frac14\int 4x\,e^{2x^2+3}\,dx = \frac14 e^{2x^2+3} + c \]

Definite integralsFundamental Theorem of Calculus, properties, powers of x

Fundamental Theorem of Calculus

\[ \int_a^b f(x)\,dx = \Big[F(x)\Big]_a^b = F(b) - F(a), \qquad \text{where } F'(x) = f(x) \]

Find any primitive, evaluate it at the upper limit, evaluate it at the lower limit, subtract (upper minus lower). The constant is left out because it cancels: $(F(b)+c) - (F(a)+c) = F(b) - F(a)$. The result is a number, not a function.

Example

\[ \int_1^3(2x+1)\,dx = \Big[x^2 + x\Big]_1^3 = (9+3) - (1+1) = 12 - 2 = 10 \]

Properties of definite integrals

PropertyMeaning
$\displaystyle\int_a^a f(x)\,dx = 0$No width, no area.
$\displaystyle\int_b^a f(x)\,dx = -\int_a^b f(x)\,dx$Swapping the limits changes the sign.
$\displaystyle\int_a^b k\,f(x)\,dx = k\int_a^b f(x)\,dx$Constants come outside.
$\displaystyle\int_a^b\big(f \pm g\big)\,dx = \int_a^b f\,dx \pm \int_a^b g\,dx$Sums split.
$\displaystyle\int_a^b f\,dx + \int_b^c f\,dx = \int_a^c f\,dx$Adjacent intervals join. Used to split at x-intercepts.
$f$ odd: $\displaystyle\int_{-a}^{a} f(x)\,dx = 0$Odd: $f(-x) = -f(x)$, e.g. $x^3$, $x$, $\sin x$. Halves cancel.
$f$ even: $\displaystyle\int_{-a}^{a} f(x)\,dx = 2\int_0^a f(x)\,dx$Even: $f(-x) = f(x)$, e.g. $x^2$, $\cos x$. Halves match.

Example (typical multiple choice)

\[ \text{Given } \int_1^4 f(x)\,dx = 7 \text{ and } \int_1^4 g(x)\,dx = 2: \] \[ \int_1^4\big(3f(x) - 2g(x)\big)\,dx = 3(7) - 2(2) = 17 \qquad \int_4^1 f(x)\,dx = -7 \qquad \int_1^4\big(f(x) + 1\big)\,dx = 7 + 3 = 10 \]

In the last one, $\int_1^4 1\,dx = [x]_1^4 = 3$, not 1. The constant is integrated over the interval width.

Definite integrals of powers of x

Simplify to powers, integrate, then evaluate. Bracket every substituted value, especially negatives.

Examples

\[ \int_1^4\sqrt{x}\,dx = \left[\frac23x^{3/2}\right]_1^4 = \frac23\left(4^{3/2} - 1^{3/2}\right) = \frac23(8 - 1) = \frac{14}{3} \] \[ \int_1^2\frac{1}{x^2}\,dx = \left[-\frac1x\right]_1^2 = \left(-\frac12\right) - \left(-1\right) = \frac12 \] \[ \int_{-1}^{2}(x^3 - x)\,dx = \left[\frac{x^4}{4} - \frac{x^2}{2}\right]_{-1}^{2} = \left(4 - 2\right) - \left(\frac14 - \frac12\right) = 2 + \frac14 = \frac94 \]

Example: unknown limit

\[ \int_0^k 2x\,dx = 9 \;\Rightarrow\; \Big[x^2\Big]_0^k = k^2 = 9 \;\Rightarrow\; k = 3 \quad (k \gt 0) \]

State which root you keep and why. If the question does not restrict $k$, both $k = 3$ and $k = -3$ may need checking.

Definite integrals and areaArea under a curve, below the axis, subdividing, symmetry, between curves

Area under a curve

\[ A = \int_a^b f(x)\,dx \qquad \text{when } f(x) \geq 0 \text{ on } [a, b] \]

The definite integral adds up thin strips of height $f(x)$ and width $dx$. When the curve is on or above the x-axis the whole way, the integral equals the area between the curve and the x-axis. Area is given in square units.

Example

\[ \text{Area under } y = x^2 \text{ from } x = 0 \text{ to } x = 3: \quad \int_0^3 x^2\,dx = \left[\frac{x^3}{3}\right]_0^3 = 9 \text{ units}^2 \]

Area below the x-axis

\[ A = \left|\int_a^b f(x)\,dx\right| \qquad \text{when } f(x) \leq 0 \text{ on } [a, b] \]

Below the axis, the heights $f(x)$ are negative, so the integral is negative. Area cannot be negative: take the absolute value, or equivalently integrate $-f(x)$.

Example

\[ y = x^2 - 4 \text{ on } [0, 2] \text{ (below the axis): } \int_0^2(x^2 - 4)\,dx = \left[\frac{x^3}{3} - 4x\right]_0^2 = \frac83 - 8 = -\frac{16}{3} \] \[ A = \frac{16}{3} \text{ units}^2 \]

Subdividing at the x-intercepts

\[ A = \left|\int_a^r f(x)\,dx\right| + \left|\int_r^b f(x)\,dx\right| \qquad \text{where } f(r) = 0 \text{ and } a \lt r \lt b \]

When the curve crosses the x-axis inside the interval, positive and negative parts cancel if integrated together. Find the x-intercepts, sketch, split the integral at each intercept, take the absolute value of each piece, then add.

Example

\[ y = x^2 - 2x = x(x-2) \text{ from } x = 0 \text{ to } x = 3. \text{ Intercepts: } x = 0, 2 \] \[ \int_0^2(x^2 - 2x)\,dx = \left[\frac{x^3}{3} - x^2\right]_0^2 = \frac83 - 4 = -\frac43 \quad\text{(below)} \] \[ \int_2^3(x^2 - 2x)\,dx = (9 - 9) - \left(\frac83 - 4\right) = \frac43 \quad\text{(above)} \] \[ A = \frac43 + \frac43 = \frac83 \text{ units}^2 \]

$\int_0^3(x^2 - 2x)\,dx = 0$. That is the net signed area, not the area. Links to 5C: the area between $y = \sin x$ and the axis over $[0, 2\pi]$ is $2 + 2 = 4$, while the integral is 0.

Using symmetry

For an even function over $[-a, a]$, compute one side and double it. For an odd function, the integral over $[-a, a]$ is 0, but the area is twice the area of one side.

Examples

\[ \text{Even: } \int_{-3}^{3}x^2\,dx = 2\int_0^3x^2\,dx = 2(9) = 18 \] \[ \text{Odd: } \int_{-2}^{2}x^3\,dx = 0, \quad\text{but area} = 2\int_0^2x^3\,dx = 2\left[\frac{x^4}{4}\right]_0^2 = 2(4) = 8 \text{ units}^2 \] \[ \text{Odd with intercepts: } y = x^3 - 4x \text{ on } [-2, 2], \text{ intercepts } -2, 0, 2 \] \[ \int_0^2(x^3 - 4x)\,dx = \left[\frac{x^4}{4} - 2x^2\right]_0^2 = 4 - 8 = -4 \;\Rightarrow\; A = 2 \times 4 = 8 \text{ units}^2 \]

State the symmetry you are using ("$f$ is odd since $f(-x) = -f(x)$"). It counts as working.

Area between two curves

\[ A = \int_a^b\big(\text{top} - \text{bottom}\big)\,dx = \int_a^b\big(f(x) - g(x)\big)\,dx \qquad f(x) \geq g(x) \text{ on } [a, b] \]

Find where the curves meet by setting them equal: those x-values are usually the limits. Decide which curve is on top by testing a point between the limits. Subtract bottom from top and integrate. This works wherever the region sits relative to the x-axis, so there is no need to split at x-intercepts. You only split where the two curves cross each other, because top and bottom swap there.

Example 1

\[ y = x \text{ and } y = x^2: \quad x = x^2 \Rightarrow x = 0, 1. \text{ Test } x = \tfrac12: \tfrac12 \gt \tfrac14, \text{ so } y = x \text{ is on top} \] \[ A = \int_0^1(x - x^2)\,dx = \left[\frac{x^2}{2} - \frac{x^3}{3}\right]_0^1 = \frac12 - \frac13 = \frac16 \text{ units}^2 \]

Example 2

\[ y = 4 - x^2 \text{ and } y = x + 2: \quad 4 - x^2 = x + 2 \Rightarrow x^2 + x - 2 = 0 \Rightarrow x = -2, 1 \] \[ \text{Test } x = 0: \; 4 \gt 2, \text{ so } y = 4 - x^2 \text{ is on top} \] \[ A = \int_{-2}^{1}\big((4 - x^2) - (x + 2)\big)\,dx = \int_{-2}^{1}(2 - x - x^2)\,dx = \left[2x - \frac{x^2}{2} - \frac{x^3}{3}\right]_{-2}^{1} \] \[ = \left(2 - \frac12 - \frac13\right) - \left(-4 - 2 + \frac83\right) = \frac76 + \frac{10}{3} = \frac92 \text{ units}^2 \]

Put brackets around the bottom function before subtracting: $(4 - x^2) - (x + 2)$, not $4 - x^2 - x + 2$.

Logarithmic integralsWeek 5C

One over x

\[ \int \frac{1}{x}\,dx = \ln|x| + c \]

This is the $n=-1$ case the power rule cannot handle. The absolute value is there because $\tfrac1x$ exists for negative $x$ but $\ln x$ does not; $\ln|x|$ covers both sides, and its derivative is $\tfrac1x$ everywhere except 0.

Example

\[ \int \frac{4}{x}\,dx = 4\int\frac1x\,dx = 4\ln|x| + c \]

Derivative over function

\[ \int \frac{f'(x)}{f(x)}\,dx = \ln|f(x)| + c \]

If the numerator is exactly the derivative of the denominator, the answer is the log of the denominator. Always differentiate the denominator first and compare it with the numerator.

Example (5C exercise)

\[ \int \frac{2x+7}{x^2+7x-3}\,dx: \quad f(x)=x^2+7x-3,\; f'(x)=2x+7 \checkmark \] \[ = \ln\left|x^2+7x-3\right| + c \]

Adjusting a constant factor

\[ \int \frac{k\,f'(x)}{f(x)}\,dx = k\ln|f(x)| + c \]

If the numerator is the derivative multiplied or divided by a constant, pull the constant out, or multiply inside and divide outside by the missing constant. This works only for constants, never for expressions containing $x$.

Example (5C exercise)

\[ \int \frac{x}{x^2-3}\,dx: \quad f'(x) = 2x, \text{ numerator has } x \] \[ = \frac12\int\frac{2x}{x^2-3}\,dx = \frac12\ln\left|x^2-3\right| + c \] \[ \int \frac{x-2x^3}{x^2-x^4}\,dx: \quad f'(x)=2x-4x^3 = 2(x-2x^3) \;\Rightarrow\; = \frac12\ln\left|x^2-x^4\right| + c \]

Linear denominator

\[ \int \frac{1}{ax+b}\,dx = \frac1a\ln|ax+b| + c \]

Special case of the previous rule: the derivative of $ax+b$ is $a$, so divide by $a$.

Example (5C mixed integration)

\[ \int \frac{2}{3x+9}\,dx = 2\cdot\frac13\ln|3x+9| + c = \frac23\ln|3x+9| + c \]

Two correct forms for $\int\frac{1}{5x}dx$: $\tfrac15\ln|x|+c$ (factor out $\tfrac15$) or $\tfrac15\ln|5x|+c$ (linear rule). Since $\ln|5x| = \ln 5 + \ln|x|$, they differ only by a constant absorbed into $c$.

Definite integral with a log

\[ \int_a^b f(x)\,dx = \Big[F(x)\Big]_a^b = F(b) - F(a) \]

Integrate, then substitute upper limit minus lower limit. No $+c$. Simplify with log laws.

Example (5C exercise)

\[ \int_2^4 \left(x - \frac1x\right)dx = \left[\frac{x^2}{2} - \ln|x|\right]_2^4 = (8-\ln4) - (2-\ln2) = 6 - \ln4 + \ln2 \] \[ \ln4 = 2\ln2 \;\Rightarrow\; = 6 - \ln 2 \approx 5.307 \]

Trigonometric integralsWeek 5C. Always in radians.

The three basic trig integrals

\[ \int \cos x\,dx = \sin x + c \qquad \int \sin x\,dx = -\cos x + c \qquad \int \sec^2 x\,dx = \tan x + c \]

Read from the derivatives: $(\sin x)' = \cos x$, $(\cos x)' = -\sin x$, $(\tan x)' = \sec^2 x$. The minus sign belongs to the integral of $\sin$, because the derivative of $\cos$ is negative.

Example (5C exercise)

\[ \int(\cos x + 6)\,dx = \sin x + 6x + c \qquad \int(\sec^2x - 3x)\,dx = \tan x - \frac{3x^2}{2} + c \]

Linear inside: divide by a

\[ \int\cos(ax+b)\,dx = \tfrac1a\sin(ax+b) + c \qquad \int\sin(ax+b)\,dx = -\tfrac1a\cos(ax+b) + c \qquad \int\sec^2(ax+b)\,dx = \tfrac1a\tan(ax+b) + c \]

Differentiating $\sin(ax+b)$ multiplies by $a$, so integrating divides by $a$. When $a$ is a fraction like $\tfrac12$, dividing by it means multiplying by 2. When $a$ is negative, the sign flips.

Examples (5C exercises)

\[ \int\sec^2(3x+2)\,dx = \frac13\tan(3x+2) + c \] \[ \int 5\sin\tfrac{x}{2}\,dx = 5\cdot\left(-\frac{1}{1/2}\cos\tfrac{x}{2}\right) + c = -10\cos\tfrac{x}{2} + c \] \[ \int\cos\left(\tfrac{\pi}{2}-x\right)dx: \; a=-1 \;\Rightarrow\; = -\sin\left(\tfrac{\pi}{2}-x\right) + c \] \[ \int\left(x^2 + 6\cos(4x-3)\right)dx = \frac{x^3}{3} + \frac64\sin(4x-3) + c = \frac{x^3}{3} + \frac32\sin(4x-3) + c \]

Derivative of the inside is present

\[ \int f'(x)\cos f(x)\,dx = \sin f(x) + c \qquad \int f'(x)\sin f(x)\,dx = -\cos f(x) + c \qquad \int f'(x)\sec^2 f(x)\,dx = \tan f(x) + c \]

The general form of the previous rule: when the inside is not linear, its derivative must appear as a factor.

Example (5C)

\[ \int\left(6x\sec^2(3x^2+1) + x\right)dx: \; f(x)=3x^2+1,\; f'(x)=6x \checkmark \] \[ = \tan(3x^2+1) + \frac{x^2}{2} + c \]

Definite trig integrals

Integrate, substitute limits in radians, use exact values. Watch brackets around negative terms.

Examples (5C exercises)

\[ \int_0^{\pi/2}\sin x\,dx = \Big[-\cos x\Big]_0^{\pi/2} = \left(-\cos\tfrac{\pi}{2}\right) - \left(-\cos 0\right) = 0 - (-1) = 1 \] \[ \int_{\pi/6}^{\pi/2}\cos 2x\,dx = \frac12\Big[\sin 2x\Big]_{\pi/6}^{\pi/2} = \frac12\left(\sin\pi - \sin\tfrac{\pi}{3}\right) = \frac12\left(0 - \tfrac{\sqrt3}{2}\right) = -\frac{\sqrt3}{4} \]

A negative result is valid. It means more of the curve lies below the x-axis than above it over that interval.

Simple substitutionWeek 5D. The reverse chain rule.

When to use it

\[ \int f\big(g(x)\big)\,g'(x)\,dx = \int f(u)\,du, \qquad u = g(x) \]

Look for a product of two things: a function inside another function, $f(g(x))$, and the derivative of that inner function, $g'(x)$ (or a constant multiple of it). The chain rule produced this shape, so substitution undoes it. The substitution also replaces $dx$: this is the part most often done wrong.

The five steps

StepAction
1Let $u = g(x)$, the inner function.
2Find $\frac{du}{dx} = g'(x)$, so $du = g'(x)\,dx$. Adjust constants: e.g. $du = 2x\,dx \Rightarrow x\,dx = \frac{du}{2}$.
3Replace $g(x)$ with $u$ and $g'(x)\,dx$ with $du$. The integral must now be entirely in $u$, including $du$. No $x$ may remain.
4Integrate with respect to $u$.
5Back-substitute $u = g(x)$. The answer must be entirely in $x$. Add $+c$.

Example (5D)

\[ \int 2x(x^2-1)^4\,dx \] \[ 1.\; u = x^2-1 \qquad 2.\; du = 2x\,dx \qquad 3.\; \int u^4\,du \qquad 4.\; \frac{u^5}{5} + c \qquad 5.\; \frac{(x^2-1)^5}{5} + c \]

Constant factor missing

\[ du = k\,g'(x)\,dx \;\Longrightarrow\; g'(x)\,dx = \frac{du}{k} \]

If the derivative is present except for a constant, solve for what is actually in the integral. The constant then comes outside.

Example (5D)

\[ \int x(x^2-3)^5\,dx: \quad u=x^2-3,\; du = 2x\,dx \Rightarrow x\,dx = \frac{du}{2} \] \[ = \frac12\int u^5\,du = \frac12\cdot\frac{u^6}{6} + c = \frac{(x^2-3)^6}{12} + c \]

Root inside

Let $u$ be the expression under the root. Convert $\sqrt{u}$ to $u^{1/2}$ before integrating.

Example (5D exercise)

\[ \int 3x^2\sqrt{4+x^3}\,dx: \quad u = 4+x^3,\; du = 3x^2\,dx \] \[ = \int u^{1/2}\,du = \frac{u^{3/2}}{3/2} + c = \frac23(4+x^3)^{3/2} + c = \frac{2\sqrt{(4+x^3)^3}}{3} + c \]

Power in the denominator

Rewrite $\frac{1}{u^n}$ as $u^{-n}$ and use the power rule. This is not a log, because the power is not 1.

Example (5D exercise)

\[ \int\frac{x+1}{(x^2+2x)^3}\,dx: \quad u = x^2+2x,\; du = (2x+2)\,dx = 2(x+1)\,dx \Rightarrow (x+1)\,dx = \frac{du}{2} \] \[ = \frac12\int u^{-3}\,du = \frac12\cdot\frac{u^{-2}}{-2} + c = -\frac{1}{4u^2} + c = -\frac{1}{4(x^2+2x)^2} + c \]

Definite integrals by substitutionWeek 5D

Change the limits (recommended)

\[ \int_{x=a}^{x=b} f\big(g(x)\big)\,g'(x)\,dx = \int_{u=g(a)}^{u=g(b)} f(u)\,du \]

The original limits are values of $x$. Once the integral is in $u$, the limits must be values of $u$. Put each $x$-limit into $u=g(x)$, integrate in $u$, and substitute the $u$-limits. Do not back-substitute.

The alternative is to do the indefinite integral, back-substitute to $x$, then use the original $x$-limits. Both give the same number; mixing them does not.

Example (5D)

\[ \int_0^1 3x^2(x^3+1)^4\,dx: \quad u = x^3+1,\; du = 3x^2\,dx \] \[ x=0 \Rightarrow u=1, \qquad x=1 \Rightarrow u=2 \] \[ = \int_1^2 u^4\,du = \left[\frac{u^5}{5}\right]_1^2 = \frac{32}{5} - \frac15 = \frac{31}{5} \]

With a constant adjustment

Example (5D exercise)

\[ \int_0^2 x\sqrt{x^2+1}\,dx: \quad u = x^2+1,\; du = 2x\,dx \Rightarrow x\,dx = \frac{du}{2} \] \[ x=0 \Rightarrow u=1, \qquad x=2 \Rightarrow u=5 \] \[ = \frac12\int_1^5 u^{1/2}\,du = \frac12\cdot\frac23\Big[u^{3/2}\Big]_1^5 = \frac13\left(5^{3/2} - 1\right) = \frac{5\sqrt5 - 1}{3} \approx 3.393 \]

With a fractional power

Example (5D exercise)

\[ \int_1^2 (3x^2-3)(x^3-3x+2)^{5/2}\,dx: \quad u = x^3-3x+2,\; du = (3x^2-3)\,dx \] \[ x=1 \Rightarrow u = 1-3+2 = 0, \qquad x=2 \Rightarrow u = 8-6+2 = 4 \] \[ = \int_0^4 u^{5/2}\,du = \frac27\Big[u^{7/2}\Big]_0^4 = \frac27\left(4^{7/2} - 0\right) = \frac27\cdot 2^7 = \frac{256}{7} \]

$4^{7/2} = (\sqrt4)^7 = 2^7 = 128$. Take the root first; the numbers stay small.

Substitution: further functionsWeek 6A. Same five steps, new function types.

Exponential inside a root

Example (6A)

\[ \int e^x\sqrt{e^x+1}\,dx: \quad u = e^x+1,\; du = e^x\,dx \] \[ = \int u^{1/2}\,du = \frac23u^{3/2} + c = \frac23(e^x+1)^{3/2} + c \]

Trig function in an exponent

Example (6A)

\[ \int 3\cos2x\,e^{\sin2x}\,dx: \quad u=\sin2x,\; du = 2\cos2x\,dx \Rightarrow \cos2x\,dx = \frac{du}{2} \] \[ = 3\int e^u\,\frac{du}{2} = \frac32e^u + c = \frac32e^{\sin2x} + c \] \[ \int x\cos x^2\,e^{\sin x^2}\,dx: \quad u = \sin x^2,\; du = 2x\cos x^2\,dx \Rightarrow = \frac12e^{\sin x^2} + c \]

Power of a trig function

$\sin^6x$ means $(\sin x)^6$. Rewrite it with brackets to see the inner function.

Example (6A)

\[ \int\cos x\,\sin^6x\,dx = \int\cos x\,(\sin x)^6\,dx: \quad u = \sin x,\; du = \cos x\,dx \] \[ = \int u^6\,du = \frac{u^7}{7} + c = \frac{\sin^7x}{7} + c \]

Negative derivative

When $u=\cos x$, $du = -\sin x\,dx$, so $\sin x\,dx = -du$. The minus sign comes outside and stays to the end.

Example (6A exercise)

\[ \int\sin x\sqrt{\cos x}\,dx: \quad u = \cos x,\; du = -\sin x\,dx \Rightarrow \sin x\,dx = -du \] \[ = -\int u^{1/2}\,du = -\frac23u^{3/2} + c = -\frac23(\cos x)^{3/2} + c = -\frac{2\sqrt{\cos^3x}}{3} + c \]

Substitution giving a log

\[ \int\frac{g'(x)}{g(x)}\,dx \;\xrightarrow{\;u=g(x)\;}\; \int\frac{du}{u} = \ln|u| + c \]

The $f'/f$ rule from 5C is a substitution with $u$ = the denominator. Either method is acceptable; show working either way.

Examples (6A)

\[ \int\frac{-2\sin2x}{\cos2x+3}\,dx: \quad u=\cos2x+3,\; du = -2\sin2x\,dx \Rightarrow = \ln|\cos2x+3| + c \] \[ \int\frac{4e^{2x}+e^x}{2e^{2x}+e^x+1}\,dx: \quad u = 2e^{2x}+e^x+1,\; du = (4e^{2x}+e^x)\,dx \Rightarrow = \ln\left|2e^{2x}+e^x+1\right| + c \]

Harder variant from the notes: $\int\frac{2e^{2x}+e^x}{2e^{2x}+2e^x+1}dx$. Here $du = (4e^{2x}+2e^x)dx = 2(2e^{2x}+e^x)dx$, so the answer is $\frac12\ln|2e^{2x}+2e^x+1| + c$.

tan and sec squared

Example (6A exercise)

\[ \int\tan2x\,\sec^22x\,dx: \quad u = \tan2x,\; du = 2\sec^22x\,dx \Rightarrow \sec^22x\,dx = \frac{du}{2} \] \[ = \frac12\int u\,du = \frac12\cdot\frac{u^2}{2} + c = \frac{u^2}{4} + c = \frac{\tan^22x}{4} + c \]

Choosing $u = \sec2x$ also works: $du = 2\sec2x\tan2x\,dx$, and the answer is $\frac{\sec^22x}{4}+c$. Since $\sec^2 = 1 + \tan^2$, the two answers differ by the constant $\frac14$. Both are correct.

Things to remember

  • Every indefinite integral ends with $+c$. Definite integrals never have $+c$.
  • Logs from integration carry absolute values: $\ln|x|$, $\ln|f(x)|$. Drop them only when the inside is always positive, e.g. $\ln(x^2+1)$ or $\ln(e^x+1)$.
  • Trig integrals use radians. Set the calculator to radian mode before evaluating anything with trig.
  • Show every step. The marking criteria say a bare correct answer may score 0, and working earns partial credit.
  • Check any indefinite answer by differentiating it. You should get the original integrand exactly.
  • Write $dx$ in every line before substitution and $du$ in every line after. Missing differentials cost notation marks.
  • Only constants can be moved in and out of an integral. A factor with $x$ in it cannot be "adjusted".
  • For definite substitution, change the limits to $u$-values and do not back-substitute. Label them ($x=0 \Rightarrow u=1$) to show the change.
  • Rewrite before integrating: roots as fractional powers, $\frac{1}{x^n}$ as $x^{-n}$, $\sin^n x$ as $(\sin x)^n$.
  • The integral of a sum is the sum of the integrals. The integral of a product is not the product of the integrals.
  • Final answers can be left in either form: $\frac23(4+x^3)^{3/2}$ or $\frac{2\sqrt{(4+x^3)^3}}{3}$. Give exact values for definite integrals unless a decimal is asked for.
  • A formula list is provided in the exam. Recognising which formula applies, and adjusting constants, is the skill being tested.
  • An integral is not always an area. Sketch the curve and find its x-intercepts before any area question.
  • Area is always positive and in units². Take the absolute value of each piece separately, then add.
  • Between two curves: top minus bottom, limits at the intersection points, split only where the curves cross each other.
  • In "find the function" questions, solve for $c$ using the given point. An answer that still has $c$ in it is incomplete.
  • Simplify before integrating: expand, split fractions over a single term, write roots as powers.
  • Swapping limits flips the sign. $\int_a^a f\,dx = 0$. A constant integrated over $[a, b]$ gives $k(b - a)$.

Conceptual mistakesMisunderstanding what a rule does or when it applies

Adjusting for a variable factor

Wrong\[ \int(x^2-1)^4\,dx = \frac{(x^2-1)^5}{5\cdot 2x} + c \]
Right\[ \text{No } 2x \text{ factor, so substitution does not apply. Expand and integrate term by term.} \]

You can only divide by the inner derivative when it is a constant. Differentiating the wrong answer with the quotient rule does not return the integrand.

Same error with trig

Wrong\[ \int\cos(x^2)\,dx = \frac{\sin(x^2)}{2x} + c \]
Right\[ \int 2x\cos(x^2)\,dx = \sin(x^2) + c \]

The "divide by a" rule is for linear insides only. For a non-linear inside, the derivative must already be in the integrand.

Using ln when the top is not the derivative of the bottom

Wrong\[ \int\frac{1}{x^2+1}\,dx = \ln(x^2+1) + c \]
Right\[ \int\frac{2x}{x^2+1}\,dx = \ln(x^2+1) + c \]

Differentiate the denominator and compare with the numerator before writing ln. If they do not match up to a constant, the log rule does not apply.

ln for other powers

Wrong\[ \int\frac{1}{x^2}\,dx = \ln x^2 + c \qquad \int\frac{du}{u^3} = \ln|u^3| + c \]
Right\[ \int x^{-2}\,dx = -\frac1x + c \qquad \int u^{-3}\,du = -\frac{1}{2u^2} + c \]

ln only comes from power $-1$. Every other power uses the power rule.

Integrating a product piece by piece

Wrong\[ \int 2x(x^2-1)^4\,dx = x^2\cdot\frac{(x^2-1)^5}{5} + c \]
Right\[ \text{Substitute } u = x^2-1 \Rightarrow \frac{(x^2-1)^5}{5} + c \]

Sums split; products do not. A product of an inner function and its derivative is the signal for substitution.

Choosing the wrong u

Wrong\[ \int\sin x\sqrt{\cos x}\,dx, \; u=\sin x \Rightarrow \int u\sqrt{\cos x}\,dx \]
Right\[ u = \cos x,\; \sin x\,dx = -du \Rightarrow -\int u^{1/2}\,du \]

If $x$ remains after substituting, the choice is wrong. Pick the inner function (inside the root, bracket or exponent), not the factor beside it. The notes mark this as "wrong sub".

Integrating with x and u mixed

Wrong\[ \int u^4\,dx = \frac{u^5}{5} + c \]
Right\[ \int u^4\,du = \frac{u^5}{5} + c, \text{ after replacing } 2x\,dx \text{ with } du \]

$dx$ must be converted to $du$ in step 3. Integrating $u^4$ with respect to $x$ is a different problem.

Mixing limits

Wrong\[ \int_0^1 3x^2(x^3+1)^4\,dx = \int_0^1 u^4\,du = \frac15 \]
Right\[ = \int_1^2 u^4\,du = \frac{31}{5} \]

Limits belong to the variable of integration. $x$-limits go with $x$, $u$-limits with $u$. Also wrong: changing to $u$-limits and then back-substituting to $x$ before evaluating.

Thinking a different-looking answer is wrong

Assumption\[ \frac{\tan^22x}{4} \ne \frac{\sec^22x}{4}, \text{ so one must be wrong} \]
Reality\[ \frac{\sec^22x}{4} = \frac{\tan^22x}{4} + \frac14 \]

Antiderivatives are only defined up to a constant. Two answers that differ by a constant are both correct. Test by differentiating both.

Rejecting a negative definite integral

Wrong\[ \int_{\pi/6}^{\pi/2}\cos2x\,dx = -\frac{\sqrt3}{4} \text{ must be an error} \]
Right\[ -\frac{\sqrt3}{4} \text{ is correct} \]

A definite integral is signed area. Area below the x-axis counts as negative.

Treating the integral as the area when the curve crosses the axis

Wrong\[ \text{Area between } y = x^2 - 2x \text{ and the axis on } [0,3] = \int_0^3(x^2-2x)\,dx = 0 \]
Right\[ \left|\int_0^2\right| + \left|\int_2^3\right| = \frac43 + \frac43 = \frac83 \]

The integral is net signed area. Pieces below the axis subtract. Split at every x-intercept inside the interval.

Absolute value on the total instead of each piece

Wrong\[ A = \left|-\tfrac43 + \tfrac43\right| = 0 \]
Right\[ A = \left|-\tfrac43\right| + \left|\tfrac43\right| = \tfrac83 \]

Make each piece positive first, then add.

Using the odd-function shortcut for area

Wrong\[ \text{Area under } y = x^3 \text{ on } [-2, 2] = 0 \text{ (odd)} \]
Right\[ \text{Integral} = 0, \quad \text{area} = 2\int_0^2 x^3\,dx = 8 \]

Odd symmetry makes the integral cancel. It doubles the area of one half.

Bottom minus top

Wrong\[ \int_0^1(x^2 - x)\,dx = -\frac16 \text{, reported as the area} \]
Right\[ \int_0^1(x - x^2)\,dx = \frac16 \]

Test a point between the intersections to find the top curve. A negative result for area between curves means the order is reversed.

Splitting between-curve areas at the x-axis

Unnecessary\[ \text{Splitting } \int_{-2}^{1}\big((4-x^2)-(x+2)\big)dx \text{ where either curve crosses the x-axis} \]
Right\[ \text{One integral, top minus bottom, from } -2 \text{ to } 1 \]

Top minus bottom is the height of the region wherever it sits. Split only where the curves themselves cross.

Integrating numerator and denominator separately

Wrong\[ \int\frac{x^4 - 3x^2}{x^2}\,dx = \frac{x^5/5 - x^3}{x^3/3} + c \]
Right\[ = \int(x^2 - 3)\,dx = \frac{x^3}{3} - 3x + c \]

No quotient or product rule exists for integration. Simplify first, then integrate term by term.

Leaving c in an application question

Incomplete\[ f'(x) = 3x^2 - 4x,\; f(1) = 5 \Rightarrow f(x) = x^3 - 2x^2 + c \]
Complete\[ c = 6 \Rightarrow f(x) = x^3 - 2x^2 + 6 \]

The given point exists to find $c$. The question wants one specific function.

Technical mistakesRight method, slip in execution

Sign of the sin integral

Wrong\[ \int\sin x\,dx = \cos x + c \]
Right\[ \int\sin x\,dx = -\cos x + c \]

Check: $\frac{d}{dx}(-\cos x) = \sin x$. The minus sign is on the integral of $\sin$, not $\cos$.

Multiplying instead of dividing by the inner derivative

Wrong\[ \int\sec^2(3x+2)\,dx = 3\tan(3x+2) + c \qquad \int\sin\tfrac{x}{2}\,dx = -\tfrac12\cos\tfrac{x}{2} + c \]
Right\[ = \tfrac13\tan(3x+2) + c \qquad = -2\cos\tfrac{x}{2} + c \]

Differentiation multiplies by $a$; integration divides by $a$. Dividing by $\frac12$ is multiplying by 2.

Dividing by a fractional power

Wrong\[ \int u^{1/2}\,du = \frac32u^{3/2} + c \]
Right\[ = \frac{u^{3/2}}{3/2} + c = \frac23u^{3/2} + c \]

Dividing by $\frac32$ means multiplying by $\frac23$. Write the intermediate step to avoid flipping it.

Negative powers

Wrong\[ \int u^{-3}\,du = \frac{u^{-4}}{-4} + c \]
Right\[ = \frac{u^{-2}}{-2} + c = -\frac{1}{2u^2} + c \]

Adding 1 to $-3$ gives $-2$, not $-4$. With negatives, "add one" moves toward zero.

Losing the power on back-substitution

Wrong\[ \frac{u^2}{4} + c = \frac{\tan2x}{4} + c \]
Right\[ \frac{u^2}{4} + c = \frac{\tan^22x}{4} + c \]

Replace every $u$ with the full expression and keep its exponent. Bracket it first: $u^2 = (\tan2x)^2$.

Losing the constant from du

Wrong\[ \int 3\cos2x\,e^{\sin2x}\,dx = 3e^{\sin2x} + c \]
Right\[ du = 2\cos2x\,dx \Rightarrow = \frac32e^{\sin2x} + c \]

Solve $du$ for exactly what appears in the integral ($\cos2x\,dx = \frac{du}{2}$) and carry the $\frac12$ through.

Double negatives when evaluating limits

Wrong\[ \Big[-\cos x\Big]_0^{\pi/2} = -\cos\tfrac{\pi}{2} - \cos0 = -1 \]
Right\[ = \left(-\cos\tfrac{\pi}{2}\right) - \left(-\cos0\right) = 0 + 1 = 1 \]

Put each substituted value in its own brackets before subtracting.

Degree mode

Wrong\[ \sin\tfrac{\pi}{3} \text{ typed in degree mode} \approx 0.0183 \]
Right\[ \sin\tfrac{\pi}{3} = \tfrac{\sqrt3}{2} \approx 0.866 \]

Calculus trig formulas only hold in radians. Use exact values where you can (table below).

Unsimplified logs

Left as\[ 6 - \ln4 + \ln2 \]
Simplify to\[ 6 - \ln 2 \]

Use $\ln a - \ln b = \ln\frac ab$, $\ln a^n = n\ln a$, $\ln1 = 0$. Multiple-choice options are usually in simplified form.

Reading trig notation

Confused\[ \sin x^2 \text{ read as } \sin^2x \]
Correct\[ \sin x^2 = \sin(x^2), \qquad \sin^2x = (\sin x)^2 \]

These have different derivatives ($2x\cos x^2$ versus $2\sin x\cos x$), so they need different substitutions.

Integrating a constant

Wrong\[ \int 5\,dx = 5 + c \qquad \int 5\,dx = c \]
Right\[ \int 5\,dx = 5x + c \]

Confusion with differentiation, where constants vanish. In integration they gain an $x$.

Coefficient in the denominator

Wrong\[ \frac{1}{2x^3} = 2x^{-3} \quad\text{or}\quad (2x)^{-3} \]
Right\[ \frac{1}{2x^3} = \frac12x^{-3} \;\Rightarrow\; \int = -\frac{1}{4x^2} + c \]

Only the $x$ moves up with a negative power. The 2 stays in the denominator as $\frac12$.

Expanding a square

Wrong\[ (\sqrt{x} + 1)^2 = x + 1 \]
Right\[ (\sqrt{x} + 1)^2 = x + 2\sqrt{x} + 1 \]

$(a + b)^2 = a^2 + 2ab + b^2$. The middle term is always there.

Negative lower limits

Wrong\[ \left[\frac{x^3}{3}\right]_{-2}^{1} = \frac13 - \frac83 \]
Right\[ = \frac13 - \left(\frac{-8}{3}\right) = 3 \]

$(-2)^3 = -8$ and $(-2)^2 = 4$. Bracket the negative number and the whole lower-limit value.

Units and +c in the wrong places

Wrong\[ \int_0^3 x^2\,dx = 9 + c \qquad A = 9 \]
Right\[ \int_0^3 x^2\,dx = 9 \qquad A = 9 \text{ units}^2 \]

No $+c$ on definite integrals. Areas carry units².
